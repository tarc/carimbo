# Phase 5 Plan 07: line-item metrics with bootstrap intervals, latency percentiles and byte-stable regrades

## Phase Goal

**As a** developer, **I want to** grade full-dataset runs field by field with confidence intervals, a silent-error rate and tagged failures, and compare any two runs case by case, **so that** I can tell real quality changes from noise.

This plan's slice: **As a** developer, **I want to** read how well rows were found and how accurate each item column is, with intervals that respect rows sharing an invoice, plus latency percentiles, and get the same bytes on every regrade, **so that** the row-level picture is as trustworthy as the headline.

<objective>
Add the pooled row-level blocks with a seeded bootstrap over invoices, per scope and per slice, replace the latency summary by nearest-rank percentiles, and prove that a regrade is byte-stable.

Purpose: the rest of EVAL-05.
Output: `items`, `installments`, `ci95` on every row column of `field_by_slice`, `stats.bootstrap`, the new latency blocks, tests.
</objective>
