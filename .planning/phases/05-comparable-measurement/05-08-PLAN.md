# Phase 5 Plan 08: compare two graded runs case by case

## Phase Goal

**As a** developer, **I want to** grade full-dataset runs field by field with confidence intervals, a silent-error rate and tagged failures, and compare any two runs case by case, **so that** I can tell real quality changes from noise.

This plan's slice: **As a** developer, **I want to** run `carimbo-evals compare` on two graded runs and read which cases regressed, which values flipped and whether the change is significant, with a refusal when the runs are not comparable, **so that** I can trust a before-and-after claim.

<objective>
Add the `compare` command per D-16, D-17 and D-18, reading two summary.json files and nothing else.

Purpose: EVAL-08. Phase 6's gate builds on this contract, so the refusals and the exit codes are costly to change (D-18).
Output: compare.py, the CLI command, test_compare.py.
</objective>
