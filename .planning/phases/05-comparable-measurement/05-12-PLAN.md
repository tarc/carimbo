# Phase 5 Plan 12: the tag list reviewed against the real failures of the dev run

## Phase Goal

**As a** developer, **I want to** grade full-dataset runs field by field with confidence intervals, a silent-error rate and tagged failures, and compare any two runs case by case, **so that** I can tell real quality changes from noise.

This plan's slice: **As a** developer, **I want to** see what the taxonomy missed on real failures and choose its final shape, **so that** the list I freeze before the holdout describes what a model actually gets wrong.

<objective>
Report the live dev run's failures against the tag rules, stop for a human decision on the final list, and apply that decision.

Purpose: D-12 allows extending the list from the dev run, then freezing it before `test` is ever run. This is the place the phase leaves for that step. Plan 05-13 records the freeze.
Review plan: Task 1 is a read-only report and the work after it depends on a human choice, so this plan does not lead with a tracer. The tagging path was traced in plan 05-04 and proven at full size in plan 05-10.
Output: a failure report in this plan's SUMMARY, and, only if the human chooses, an extended rule list with its version bump and regraded copies.
</objective>
