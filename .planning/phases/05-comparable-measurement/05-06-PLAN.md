# Phase 5 Plan 06: silent errors, tag counts and honest run status in the summary

## Phase Goal

**As a** developer, **I want to** grade full-dataset runs field by field with confidence intervals, a silent-error rate and tagged failures, and compare any two runs case by case, **so that** I can tell real quality changes from noise.

This plan's slice: **As a** developer, **I want to** read how many invoices passed the validators and were still wrong, with wrong payment values apart from cosmetic errors, plus counted failure tags and a flag for unfinished runs, **so that** the worst failures are visible and a broken run cannot pass as a clean one.

<objective>
Add to the summary the silent-error rate and its payment split, per-field wrong counts on success cases, tag counts, the incomplete flag, and the derived wrap-hazard counts.

Purpose: EVAL-06, the counted half of EVAL-07, the infrastructure half of EVAL-04, and research finding 1.
Output: the `payment` flag on wrong values, `render_hazards` per case, new summary blocks and summary.md sections, test_silent_errors.py.
</objective>
