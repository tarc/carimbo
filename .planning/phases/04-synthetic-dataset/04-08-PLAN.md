# Phase 4 Plan 08: decision record D-40, the reviewer-facing docs and the phase gate

**As a** developer, **I want to** evaluate against a seeded dataset of at least 150 varied and deliberately hard invoices whose ground truth is proven valid, **so that** measured accuracy reflects realistic difficulty instead of a few clean cases.

This plan's slice: **As a** reviewer, **I want to** read how the dataset was built, what it promises and how to regenerate and check it, **so that** I can trust the numbers later phases publish on it.
