# Phase 3.1 Plan 01: the Decision contract, its exported schemas and generated model

## Phase Goal

**As a** developer, **I want to** have an agent read a case's extracted invoice and validator findings through read-only MCP tools and return a typed approve, reject or escalate decision, graded like extraction, **so that** the project shows an agent taking action with tools under the same measured discipline (D-26).

This plan's slice: **As a** developer, **I want to** export a typed Decision from the C# Domain to a committed JSON Schema and a generated Pydantic model, **so that** the agent's structured output, the endpoint's response and the Python grader all read one contract.

<objective>
Extend the Domain Decision record to the shape the agent returns (evidence citations, reason, outcome, cause) and export it through the same Wire.Options, schema export, model-facing projection and Pydantic codegen chain as Invoice.

Purpose: AGT-02 (typed Decision with reason and evidence, per phase decisions D-13 and D-14) and the AGT-04 grading contract depend on one exported Decision schema; RESEARCH Open Question 4 is decided here as one Decision type. The phase decision records D-34 to D-37 (labelling rule, loop semantics, decision-1 contract, cache v2) are written by plan 03.1-12 in this same wave, so they exist before any wave-2 plan implements them.
Output: Decision.cs, CanonicalSchema.Export(Type), ModelFacingSchema, two committed decision schema files, decision_generated.py, Domain and Python tests.
</objective>
