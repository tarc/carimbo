# Phase 3.1 Plan 01: the Decision contract, its exported schemas and generated model, and the phase decision records

## Phase Goal

**As a** developer, **I want to** have an agent read a case's extracted invoice and validator findings through read-only MCP tools and return a typed approve, reject or escalate decision, graded like extraction, **so that** the project shows an agent taking action with tools under the same measured discipline (D-26).

This plan's slice: **As a** developer, **I want to** export a typed Decision from the C# Domain to a committed JSON Schema and a generated Pydantic model, **so that** the agent's structured output, the endpoint's response and the Python grader all read one contract.

<objective>
Extend the Domain Decision record to the shape the agent returns (evidence citations, reason, outcome, cause), export it through the same Wire.Options, schema export, model-facing projection and Pydantic codegen chain as Invoice, and record the phase's contract decisions D-34 to D-37 before any implementing plan runs.

Purpose: AGT-02 (typed Decision with reason and evidence, per phase decisions D-13 and D-14) and the AGT-04 grading contract depend on one exported Decision schema; RESEARCH Open Question 4 is decided here as one Decision type. Writing the decision records first fixes the case labelling rule (phase D-09), the loop semantics, the decision-1 contract and the cache v2 rules that plans 02 to 11 implement.
Output: Decision.cs, CanonicalSchema.Export(Type), ModelFacingSchema, two committed decision schema files, decision_generated.py, Domain and Python tests, DECISIONS D-34 to D-37.
</objective>

cases are generated by `dotnet/tools/DecisionCases` from specs kept in code (a skeleton base case mapped by NfeXmlMapper, a mutation, a forced status for typed failures), validated by the real InvoiceValidator at the skeleton as_of_date, and written to `data/decision/` (cases/<case_id>.json, policy.json, manifest.json, expected.json), with `just decision-cases-check` failing on any byte difference; a tool_use answer on step MaxSteps ends with escalate / step_budget_exhausted and its tools are not run; a model refusal, max_tokens, an unparseable or schema-violating Decision, a tool_use answer with no tool call, and any gateway failure including cache_miss are typed failures (status refused, truncated, schema_invalid or infrastructure_failure) with no decision, never escalate causes;
