## Accomplishments

- **Tracer (Task 1).** The ScriptedHost answers a request without a document from `<responses dir>/decisions/<case_id>.json`, step `FollowUps.Count / 2`, reading the case id with `AgentPromptCatalog.TryReadCaseId`. A step may carry `tool_calls`, `thinking` and the same `failure`, `usage`, `latency_ms`, `model` and `stop_reason` members as an extraction answer; `tool_use` maps to `LlmStopReason.ToolUse`. The extraction e2e passed unchanged. `dc-001` travels over the Tools host and the Api as separate processes to a graded summary (accuracy 1 of 1).
- **Every path in the e2e (Task 2).** Eight cases at concurrency 2 (`accuracy` 8/8, `cause_accuracy` 4/4, `citations` 8/8, `guard.overridden` 1, decisions approve 2, reject 2, escalate 4; the escalations are exactly dc-003 policy_warning, dc-005 and dc-008 extraction_not_success, dc-006 over_limit). A `--cache-mode read_only` rerun: all 16 answered steps hit with `http_attempts` 0, every `incurred_cost_usd` `0.00000000`, `run.json` `spent_usd` 0 and the same `notional_usd`. Faults on one shared scripted host: dc-001 budget (6 steps, the last step's two calls skipped), dc-004 unlisted tool (`unknown_tool`), dc-005 approve overridden by the guard, dc-007 refusal (counted under `refused`, excluded from accuracy: 1 of 3), a direct POST of dc-999 (`is_error`); a closed Tools host (`source: list`, zero steps, zero tokens); `--case dc-999` exits 2 and writes nothing; no key exits 2.
- **Golden decision-1 fixtures (Task 3).** `DecisionGoldenResponseTests` renders decided, guard_override, tool_failed, step_budget_exhausted, refused, schema_invalid, cache_hit, cache_miss and overrides (a verbatim POST of the hand-written `decision-request.json`). Run latency and every tool call's measured latency are normalised to 0; the directory is checked for the exact file set; `AssertNoSecretsOrPaths` runs on each. `just golden` rewrites both golden sets (a repeated `--filter-class` works on this runner: 25 tests ran, 14 extraction plus 11 decision). `test_decision_contract.py` parses every golden with the strict `DecisionResponse` and pins statuses, deciders, a guard override, a tool failure, the budget, a hit and a miss; the 14 plan-05 models needed no change.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The plan's request-example assertion contradicted its own scenario**
- **Found during:** Task 3
- **Issue:** The plan's pytest behavior says `decision-request.json` equals `build_decision_payload("dc-001", {"cache_mode": "read_only", "replicate_salt": "r1", "model": "claude-haiku-4-5"})`, but the `overrides` golden is that file posted verbatim and the scenario is described as model `claude-sonnet-5-5`, salt `r1`, cache_mode `off`. Both cannot hold, and a `read_only` request on a host without a cache is a 400.
- **Fix:** The file carries model `claude-sonnet-5-5`, `cache_mode` `off`, `replicate_salt` `r1`; pytest asserts `build_decision_payload("dc-001", {"cache_mode": "off", "replicate_salt": "r1", "model": "claude-sonnet-5-5"})` equals it and that the golden's `effective` echoes every override.
- **Files modified:** data/contract/decision-request.json, python/tests/test_decision_contract.py
- **Commit:** 81c2adb

### Process notes (not deviations from behavior)

- **Shared golden helpers.** `Render`, `AssertGolden`, `AssertNoSecretsOrPaths` and `UpdateMode` in `GoldenResponseTests` became `internal` so the decision class reuses them instead of copying; `AssertGolden` now derives the directory name in its message from the path. The existing 14 goldens are byte-identical and their tests pass.
- **Module-scoped fault host.** The plan suggested a class-level responses_dir override. Scripts are keyed by case id, so one module-scoped host serves all fault tests (a class-scoped instance-method fixture is deprecated by pytest); the Tools host is also started once per module. The module takes about 18 s.
- **`dotnet`, `just` and `uv` were run directly** (on PATH) instead of through `devenv shell --`.
- **AGENTS.md** also had two unrequested one-line updates for consistency: the `just golden` and `just e2e` table rows and the `data/contract/` layout line now mention the decision files.

**Total deviations:** 1 auto-fixed (Rule 1, a plan inconsistency). **Impact:** none on the contract; the request example is internally consistent.
