# Phase 03.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | xUnit v3 4.0.1 on Microsoft.Testing.Platform (.NET); pytest 9.1.1 + pytest-asyncio (Python) |
| **Config file** | `global.json` (MTP runner), `python/pyproject.toml` (markers `e2e`, `live`, deselected by default) |
| **Quick run command** | `devenv shell -- sh -c 'cd dotnet && dotnet test --project tests/<Project>'` or `devenv shell -- uv run --project python pytest python/tests -q -k <area>` |
| **Full suite command** | `devenv shell -- just check` |
| **Estimated runtime** | ~300 seconds (full), ~30 seconds (single project) |

---

## Sampling Rate

- **After every task commit:** run the single affected test project or pytest selection
- **Per-task commands stay targeted** (one test project, test class or pytest file). The whole-suite gates (`just dotnet-check`, `just py-check`, `just e2e`, `just check`) run only from each plan's `<verification>` block: at plan end, or at segment end just before a human checkpoint (plans 03.1-07 and 03.1-11)
- **After every plan wave:** `just dotnet-check` and `just py-check`; `just schema-check` after Domain/schema changes; `just e2e` after ScriptedHost or runner changes
- **Before `/gsd-verify-work`:** `just check` green with no provider key, then the human-gated live evidence (`just agent-probe`, `just decisions`) recorded
- **Max feedback latency:** 300 seconds
