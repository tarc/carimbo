# Phase 3.1 Plan 08: the hand-written agent loop decides a case over MCP

## Phase Goal

**As a** developer, **I want to** have an agent read a case's extracted invoice and validator findings through read-only MCP tools and return a typed approve, reject or escalate decision, graded like extraction, **so that** the project shows an agent taking action with tools under the same measured discipline (D-26).

This plan's slice: **As a** developer, **I want to** run the agent loop on a committed case against the real Tools host and a scripted model, **so that** I can see it read the case through MCP, decide, escalate when it must, and replay from the cache for free.

<objective>
Create Carimbo.Agent: settings bounded like Extraction:MaxRepairs, the agent contract (agent-001 prompt, Decision model-facing schema), an MCP toolbox that connects per run and refuses non-read-only servers, and AgentRunner, the hand-written loop with the step budget, the tool-failure and budget escalations, the deterministic status guard and typed model failures. Proven first end to end on dc-001 over the in-process Tools host with a cached replay.

Purpose: AGT-02 (hand-written loop with a configured step budget ending in a typed Decision, no framework) and AGT-03 (budget exhaustion, a failed tool call and a non-success extraction each escalate with the cause recorded; the Decision is returned and nothing executes it), plus the loop half of AGT-05, per phase decisions D-05, D-10 to D-15, D-35, D-38 and the two user decisions after research (typed failures are not escalate causes; the guard makes its own recorded status call).
Output: Carimbo.Agent, Carimbo.Agent.Tests.
</objective>
