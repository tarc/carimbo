# Phase 3.1 Plan 02: the model seam carries tool turns, and the response cache replays them

## Phase Goal

**As a** developer, **I want to** have an agent read a case's extracted invoice and validator findings through read-only MCP tools and return a typed approve, reject or escalate decision, graded like extraction, **so that** the project shows an agent taking action with tools under the same measured discipline (D-26).

This plan's slice: **As a** developer, **I want to** send and replay multi-step tool-use conversations through the existing gateway decorators, **so that** an agent run can be cached and replayed at zero cost like an extraction run.

<objective>
Grow the Carimbo-owned gateway records with tool definitions, content blocks and tool results (additively; extraction call sites keep compiling), key tool conversations with llm-cache-key-2 while legacy requests keep the exact v1 key, and store tool_use answers so a whole agent run replays from the cache. Proven end to end through the decorator stack before the key is pinned.

Purpose: AGT-06 (a rerun replays from the Phase 3 response cache at no cost) and the gateway half of AGT-02, per D-37 (recorded by plan 03.1-12 in this same wave; this plan's action restates every rule it needs) and RESEARCH Patterns 3 and 4. The Anthropic adapter's mapping of the new members is plan 04; this plan only keeps it compiling.
Output: LlmContracts additions, cache key v2, entry v2, storage of tool_use answers, tests.
</objective>
