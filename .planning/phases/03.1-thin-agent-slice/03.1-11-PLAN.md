# Phase 3.1 Plan 11: a capped live run of the decision cases, a free replay, and published results

## Phase Goal

**As a** developer, **I want to** have an agent read a case's extracted invoice and validator findings through read-only MCP tools and return a typed approve, reject or escalate decision, graded like extraction, **so that** the project shows an agent taking action with tools under the same measured discipline (D-26).

This plan's slice: **As a** developer, **I want to** run the eight decision cases against the real model through one capped command and replay them for free, **so that** the agent's measured decision quality is published evidence anyone can rerun from the cache.

<objective>
Add the `just decisions [max_cost] [cache_mode]` live recipe (two hosts, capped runner, grading), have a human run it once live and once in read_only, verify the replay made zero model calls, and publish the runs and the measured results.

Output: decisions recipe, docs, evals/results copies, README results.
</objective>
