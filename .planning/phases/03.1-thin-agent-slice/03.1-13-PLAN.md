# Phase 3.1 Plan 13: what the agent sees of a case, and the pinned agent-001 instructions

## Phase Goal

**As a** developer, **I want to** have an agent read a case's extracted invoice and validator findings through read-only MCP tools and return a typed approve, reject or escalate decision, graded like extraction, **so that** the project shows an agent taking action with tools under the same measured discipline (D-26).

This plan's slice: **As a** developer, **I want to** define once what each read-only tool returns for a committed case and the exact instructions the agent receives, **so that** the Tools host, the live probe and the agent loop all serve and send the same pinned text, with no label in reach.

<objective>
Add CaseToolCatalog (the tool names, descriptions and JSON results the agent can see) and AgentPromptCatalog (the pinned agent-001 instructions that state labelling rule decision-labels-1 in prose, and the user-turn format) to Carimbo.Decisions, each pinned by tests over the committed decision cases. Split out of plan 03.1-03 to keep that plan within the per-plan file budget; the Tools host (03.1-06), the live probe (03.1-07) and the agent loop (03.1-08) consume both.

Purpose: AGT-01 (what the read-only tools return, phase decisions D-02 and D-03), the instructions half of AGT-02 (phase decision D-05: the first user turn gives only the case id and the task) and the rendering half of AGT-04's label-leak guard; RESEARCH Open Question 5 is decided here (one pinned prompt, no prompt_version override, recorded in D-36).
Output: CaseToolCatalog.cs, AgentPromptCatalog.cs, CaseToolCatalogTests.cs, AgentPromptTests.cs.
</objective>
