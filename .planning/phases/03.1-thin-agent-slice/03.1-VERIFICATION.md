### Judging the 7/8 result

No success criterion, requirement (AGT-01..06) or goal clause sets an accuracy target. The goal is measured discipline: graded, reproducible, with tool calls/steps/tokens/cost/trace recorded. That holds: both runs grade to identical numbers, the replay is free, and the miss is shown rather than hidden.

- **dc-004 miss: documented limitation, not a gap.** Independently reproduced from `cases.jsonl`: the model cited `recipient.tax_id 69979991000100` and `buyer_cnpj CARIMBO0000177`, then wrote "recipient tax ID matches policy" and approved (label: reject, rule 2). This is model behavior on one case in one run, published verbatim in README and in the `summary.md`. The README states that citation validity measures provenance, not value correctness (D-36, D-39), and that the guard only checks extraction status. Candidate fixes are left undecided on purpose. It is a finding for Phase 5 (silent-error rate, failure taxonomy) or a later agent iteration, not a blocker for 3.1.
- **Unverified live thinking echo: documented limitation, not human_needed.** The roadmap and requirements do not require thinking-model support. D-38 and COVERAGE.md record it as unproven live, pinned offline by the Llm adapter tests and cache v2 entries. The default model does not think, so the delivered path is unaffected. Open until a live step-1 answer carries a thinking block.
