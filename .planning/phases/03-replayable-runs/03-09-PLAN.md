# Phase 3 Plan 09: golden eval-response fixtures checked by both stacks

## Phase Goal

**As a** developer, **I want to** replay eval reruns from a request-hash cache and see every model call as a costed span in a local trace viewer, **so that** I can iterate on prompts and graders without paying twice and can trace any case back to its model calls.

This plan's slice: **As a** developer, **I want to** have the .NET tests emit golden eval responses that pytest parses strictly, **so that** a breaking change to the response contract fails CI before any run depends on it.

<objective>
Emit golden eval-response fixtures from the .NET tests (compare by default, rewrite with `just golden`), parse each with strict Pydantic models in pytest, and check one hand-written contract 3 request in both directions (D-32).

Purpose: API-04 and success criterion 5.
Output: GoldenResponseTests, eleven generated fixtures, one request fixture, contract.py, test_contract_golden.py, build_payload, `just golden`, docs.
</objective>
