# Phase 3 Plan 03: the response cache on by default in Development and Eval, proven by a read_only replay over HTTP

## Phase Goal

**As a** developer, **I want to** replay eval reruns from a request-hash cache and see every model call as a costed span in a local trace viewer, **so that** I can iterate on prompts and graders without paying twice and can trace any case back to its model calls.

This plan's slice: **As a** developer, **I want to** have every eval request in Development cached by default and a rerun answered from that cache, **so that** I never pay twice for the same request unless I ask to, while production never runs a cache.

<objective>
Wire the 03-01 cache into the Api composition root on by default in Development and Eval at .cache/llm under the content root, off and refused in every other environment (D-27 as decided by the user on 2026-10-15), keep every hermetic test off the default cache, prove a read_only replay over HTTP in process, and make the extractor stamp the prompt version, cache mode and replicate salt onto every request.

Purpose: the "enabled in dev/eval and off in production" half of LLM-04, the HTTP replay of LLM-05, and the "prompt version is part of the cache key" half of EXT-05 (the extractor now sends it). Contract 3 (03-04), retries (03-05), spans (03-07) and every later plan start from this composition.
Output: Program.cs cache block and DecorateGateway, TestHost hermetic default, e2e per-test cache directory, ExtractionOverrides and stamping, CacheConfigurationTests, scripted host attempts.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Configuration → composition root | Llm:Cache:* and the environment decide whether stored answers can be served at all |
| Api process → local disk | The default-on cache writes entry files under the content root |
| Test and developer runs → shared cache directory | A default directory could let one run answer another's requests |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
