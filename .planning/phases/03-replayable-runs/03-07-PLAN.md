# Phase 3 Plan 07: every model call is a costed span on the eval request's trace

## Phase Goal

**As a** developer, **I want to** replay eval reruns from a request-hash cache and see every model call as a costed span in a local trace viewer, **so that** I can iterate on prompts and graders without paying twice and can trace any case back to its model calls.

This plan's slice: **As a** developer, **I want to** look up the trace id of any eval response and find one span per model call with model, tokens and cost, **so that** I can trace a case back to its model calls without any prompt, answer or document leaking into the traces.

<objective>
Add TracingLlmGateway (outermost decorator, BCL ActivitySource, allowlisted attributes, D-31), register OpenTelemetry tracing in the Api with the ASP.NET Core server instrumentation, an AlwaysOn sampler set in code (D-31) and a conditional OTLP exporter, and prove with the in-memory exporter that the model-call spans share the response's trace id and carry model, tokens and cost but no content.

Purpose: LLM-03 and the export half of success criterion 2 (the viewer itself is 03-02, the live lookup is 03-10).
Output: four pinned packages, LlmTelemetry and TracingLlmGateway, Program.cs wiring, wiring and unit tests.
</objective>
