# Phase 3 Plan 04: eval contract 3 and replay through the documented commands

## Phase Goal

**As a** developer, **I want to** replay eval reruns from a request-hash cache and see every model call as a costed span in a local trace viewer, **so that** I can iterate on prompts and graders without paying twice and can trace any case back to its model calls.

This plan's slice: **As a** developer, **I want to** rerun a recorded eval with `carimbo-evals run --cache-mode read_only`, **so that** the rerun makes zero model calls and every record shows it was a replay.

<objective>
Bump the eval contract to "3" (D-29), add the per-request cache_mode and replicate_salt overrides with field-specific validation, expose the cache block on every attempt, and carry the overrides from the runner CLI through the endpoint to the cache. Prove criterion 1 end to end through the real commands against the scripted host.

Purpose: LLM-05 (replay, refresh, never-cached failures) and LLM-04 (salt misses) through the whole stack, and the cache half of API-02.
Output: contract 3 endpoint, runner and CLI flags, extended e2e test.
</objective>
