# Phase 3 Plan 10: live proof: a paid seeding run, a free replay and a trace lookup

## Phase Goal

**As a** developer, **I want to** replay eval reruns from a request-hash cache and see every model call as a costed span in a local trace viewer, **so that** I can iterate on prompts and graders without paying twice and can trace any case back to its model calls.

This plan's slice: **As a** developer, **I want to** run the skeleton cases live once, replay them for free and open their traces in Jaeger, **so that** the cache and the spans are proven against the real model, not only the scripted one.

Give `just skeleton` a cache mode and a persistent cache directory, then, after an explicit spend approval, run one capped live seeding run, one read_only replay and a Jaeger trace lookup, and publish the evidence.

Purpose: the live proof of success criteria 1 and 2; the offline proofs (e2e and wiring tests) remain the CI proof (CI uses no provider key).
Output: recipe change and its static test, two copied run directories under evals/results, README and AGENTS updates, the spend record in the SUMMARY.
</objective>
