# Phase 3 Plan 08: per-request model, prompt version and repair budget

## Phase Goal

**As a** developer, **I want to** replay eval reruns from a request-hash cache and see every model call as a costed span in a local trace viewer, **so that** I can iterate on prompts and graders without paying twice and can trace any case back to its model calls.

This plan's slice: **As a** developer, **I want to** choose the model, the prompt version and the repair budget per eval request and see them echoed, **so that** I can compare configurations without restarting the Api, and the cache keeps their results apart.

<objective>
Add a prompt catalog (extract-003 default, extract-002 restored, D-30) and the remaining API-02 overrides: model (priced models only), prompt_version (catalogued only) and max_repairs (0..5), resolved once per request in the extractor and echoed in effective. Expose them as runner flags and prove through the documented commands that each one changes the cache key or the attempt count.

Purpose: API-02 complete, EXT-05 complete (prompt version in key and metadata with a real second version), and criterion 1's "a different model or prompt version misses the cache".
Output: PromptCatalog, extractor and endpoint changes, CLI flags, tests at every layer.
</objective>
