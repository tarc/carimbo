# Phase 3 Plan 05: one retry owner, the SDK, with backoff

## Phase Goal

**As a** developer, **I want to** replay eval reruns from a request-hash cache and see every model call as a costed span in a local trace viewer, **so that** I can iterate on prompts and graders without paying twice and can trace any case back to its model calls.

This plan's slice: **As a** developer, **I want to** have transient provider errors retried with backoff by exactly one policy, **so that** a passing 529 does not become an infrastructure failure in a measured run and retries never multiply spend.

<objective>
Make the Anthropic SDK retry the single retry policy (D-28): default MaxRetries 2, bounded 0..5, visible in the startup log, and prove with failing fake transports that the composed gateway chain adds no second retry layer. Add a static guard against resilience packages and hand-written retry handlers.

Purpose: LLM-01 and success criterion 3.
Output: Program.cs default and bound, gateway docs, retry tests at the SDK, chain and host level, static guard.
</objective>
