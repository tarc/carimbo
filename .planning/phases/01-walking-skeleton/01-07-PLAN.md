# Phase 1 Plan 07: Committed skeleton cases from one seeded command

## Phase Goal

**As a** developer, **I want to** generate a few synthetic DANFEs, extract them live through the .NET eval endpoint and grade the stored results from Python, **so that** the whole measurement loop runs end to end on real code before any breadth is added.

<objective>
Give the generator a command-line surface and commit its output. `carimbo-datagen build` writes the three skeleton cases (D-05) and a manifest. `carimbo-datagen check` regenerates and compares. A default-suite test asserts that the committed bytes equal a regeneration, which is how CI regenerates and checks byte identity (D-07).

Purpose: the spike (01-10), the runner and grader (01-09) and the live skeleton (01-13) all read `data/skeleton/`.
Output: `cli.py`, seven data files and a strengthened `test_datagen.py`.
</objective>

  <action>
Create `python/src/carimbo_datagen/cli.py` with `app = typer.Typer(no_args_is_help=True)` and two commands.

`build --seed INT (default MASTER_SEED) --out PATH (default data/skeleton) --case TEXT (repeatable; default all CASE_IDS)`:
- For each case, write `<case_id>.xml` from build_nfe_xml and `<case_id>.pdf` from render_danfe.
- Write each file to a temporary name in the same directory, then `os.replace`, so an interrupted run never leaves a half-written committed file.
- Then write `manifest.json` as `json.dumps(..., indent=2, sort_keys=True, ensure_ascii=False)` plus "\n". Fields:
  - `dataset` "skeleton", `dataset_version` "skeleton-001", `master_seed`, `python` "3.12" (fixed major.minor, never the patch level)
  - `generator`: package versions from `importlib.metadata.version` for carimbo, brazilfiscalreport, fpdf2, python-barcode, faker and lxml
  - `cases`: a list sorted by case_id of `{case_id, xml, xml_sha256, pdf, pdf_sha256, pages, tags}`. Tags: case-001 `["numeric_cnpj", "simples_nacional", "single_page"]`; case-002 `["alphanumeric_cnpj", "simples_nacional", "single_page"]`; case-003 `["many_items", "multi_page", "numeric_cnpj", "simples_nacional"]`.
- Print one line per case with its page count and short hashes.
- The manifest carries no timestamps, hostnames, absolute paths or interpreter patch versions, so it is identical across machines.

`check --seed INT --dir PATH (default data/skeleton)`:
- Regenerate into a `tempfile.TemporaryDirectory`, compare every file byte for byte with `--dir` (including manifest.json), print each differing or missing path, and exit with code 1 if any differ, else 0.

Expose `build_dataset(seed: int, out_dir: Path, case_ids: Sequence[str]) -> dict` (returns the manifest) so tests call it without the CLI.
