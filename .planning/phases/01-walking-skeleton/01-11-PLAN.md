# Phase 1 Plan 11: Cost from a versioned pricing table on every call

## Phase Goal

**As a** developer, **I want to** generate a few synthetic DANFEs, extract them live through the .NET eval endpoint and grade the stored results from Python, **so that** the whole measurement loop runs end to end on real code before any breadth is added.

<objective>
Price every model call in the gateway layer from a versioned table. The table lives as data (`pricing.json`), not as constants in code. It covers all five token classes, resolves dated snapshot ids through aliases, and never reports a silent zero. A decorator applies it to whichever `ILlmGateway` is registered, so scripted, fake and real gateways all report cost the same way.

Purpose: the runner's cost cap (01-09) and the live runs (01-12, 01-13) depend on correct, attributable cost.
Output: `LlmPricing.cs`, `pricing.json`, the `Carimbo.Llm.Tests` project, and the cost fields populated in eval responses.
</objective>
