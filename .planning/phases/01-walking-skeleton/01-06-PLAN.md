`ids.py` (pure, stdlib only):
- `char_value(ch)` returns `ord(ch) - 48`, which is valid for 0-9 and A-Z.
- `cnpj_check_digits(base12: str) -> str` uses weights (5,4,3,2,9,8,7,6,5,4,3,2), then (6,5,4,3,2,9,8,7,6,5,4,3,2) for the second digit; a remainder below 2 gives 0, else 11 minus the remainder.
- `is_valid_cnpj(cnpj: str) -> bool` uses the pattern `^[A-Z0-9]{12}[0-9]{2}$` plus the digits.
- `make_cnpj(rng: random.Random, *, alphanumeric: bool) -> str` builds an 8-character root (digits only, or uppercase A-Z0-9 containing at least one letter), then branch "0001", then the check digits. It rejects roots made of one repeated character.
- `access_key_check_digit(key43: str) -> int` uses weights 2..9 cycling right to left over char_value, with the same remainder rule (research mod-11 oracle).
- `make_access_key(*, uf: int, year: int, month: int, cnpj: str, model: int, series: int, number: int, emission_type: int, numeric_code: int) -> str` lays out cUF(2) AAMM(4) CNPJ(14) mod(2) serie(3) nNF(9) tpEmis(1) cNF(8) cDV(1).
- `ACCESS_KEY_PATTERN` constant.

`spec.py`:
- Frozen dataclasses: `PartySpec(cnpj, name, street, number, district, city, uf, cep)`; `ItemSpec(code, description, ncm, cfop, unit, quantity: Decimal, unit_price: Decimal)` with a `total` property quantized to 0.01 using ROUND_HALF_UP; `CaseSpec(case_id, issue_datetime, series, number, numeric_code, issuer, recipient, items, access_key)`, where issue_datetime is timezone-aware at -03:00, with a `total_amount` property that sums item totals.
- `MASTER_SEED = 20261004`.
- `CASE_IDS = ("case-001", "case-002", "case-003")` with profiles, per D-05 and D-06 (one tax regime: Simples Nacional, CRT 1, CSOSN 102):
  - case-001: numeric CNPJs, 3 items.
  - case-002: alphanumeric issuer CNPJ and numeric recipient, 4 items. This resolves research Open Question 3 in favour of an early proof of the alphanumeric pattern.
  - case-003: numeric CNPJs and `MULTIPAGE_ITEMS` items. Start at 80 and raise it until the Task 2 page-count test passes.
- `build_case_spec(master_seed: int, case_id: str) -> CaseSpec`:
  - Use `rng = random.Random(f"{master_seed}:{case_id}")`, never global random state.
  - Seed `Faker("pt_BR")` through `seed_instance(rng.getrandbits(64))`.
  - Company names are a Faker company or last name plus the suffix " SINTETICA LTDA", truncated to 60 characters with the marker kept.
  - Addresses come from Faker pt_BR, restricted to a fixed map of UF sigla to IBGE code (SP 35, RJ 33, MG 31, PR 41, RS 43).
  - The issue datetime falls between 2026-01-01 and 2026-09-30 at -03:00. Series is 1-9, number 1-999999, numeric_code 8 digits different from the number, model 55, emission type 1.
  - Item descriptions and NCM/CFOP come from a small fixed list of plausible goods, chosen by rng. Quantities and prices are Decimal with 2-4 decimal places from rng.
