# Phase 2 Plan 07: ground truth and validators agree before any model is involved

## Phase Goal

**As a** developer, **I want to** have every extraction target the full DANFE-visible invoice, pass deterministic validators and be repaired within a bounded budget, **so that** extracted invoices carry hard guarantees before anything is measured at scale.

This plan's slice: **As a** developer, **I want to** map every committed NF-e XML to the target with one documented .NET mapper and prove the validators find no error in it, **so that** a validator finding on a model answer means the answer disagrees with a DANFE that is itself consistent.

<objective>
Create `Carimbo.GroundTruth` (BCL-only XML → Invoice mapper following docs/DANFE-MAPPING.md, CONTEXT D-05), the ground-truth gate over the manifest (D-17), mapper rule tests and a doc-drift test.

Purpose: DOM-02 (the mapping is documented and implemented), VAL-03 and VAL-04 exercised on real ground truth. Phase 4 (DATA-04) reuses this gate at scale, which is why the mapper is a project rather than test-only code (RESEARCH Open Question 5).
Output: `dotnet/src/Carimbo.GroundTruth/*`, gate, mapper and doc tests in Carimbo.Validation.Tests.
</objective>

Mapping rules (identical to docs/DANFE-MAPPING.md and to the Python reader of plan 02-01): access_key = `infNFe/@Id` minus `NFe`; number, series as integers from `ide/nNF`, `ide/serie`; issue_date = first 10 characters of `ide/dhEmi` parsed as a date (never converted to UTC); operation_nature = `ide/natOp`; issuer from `emit` (CNPJ, xNome, IE verbatim or null when absent or empty, enderEmit/UF); recipient from `dest` (CNPJ → kind Cnpj or CPF → kind Cpf, xNome, IE or null, enderDest/UF); items per `det` in document order (cProd, xProd, NCM, CFOP, uCom; qCom and vUnCom rounded half-up to 4 decimals; vProd to 2; cst_csosn = `orig` of the single `imposto/ICMS` child + `CSOSN` when `emit/CRT` is 1 or 4, else `CST`; vBC, pICMS, vICMS of that child; `IPI/IPITrib` pIPI and vIPI; absent tax values 0.00); totals from `total/ICMSTot` (vBC, vICMS, vBCST, vST, vProd, vFrete, vSeg, vDesc, vOutro, vIPI, vNF; absent 0.00); installments from `cobr/dup` (nDup, dVenc, vDup), empty without `cobr`. Decimals are parsed with `decimal.Parse(text, NumberStyles.AllowDecimalPoint | NumberStyles.AllowLeadingSign, CultureInfo.InvariantCulture)`.

Execution environment: `devenv shell -- <cmd>` from the repo root; xUnit `Assert` only.
