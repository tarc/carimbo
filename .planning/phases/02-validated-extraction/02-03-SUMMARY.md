# Phase 2 Plan 03: a repair turn can reach the provider, with the PDF cached, proven live

**The gateway now sends follow-up repair turns with an ephemeral cache breakpoint on the PDF block, and a live probe on claude-haiku-4-5 shows the provider accepts the committed v2 schema unchanged and a cached two-turn conversation returns schema-valid invoices.**

## Performance

- **Duration:** about 35 min
- **Completed:** 2026-10-08
- **Tasks:** 3 (1 tracer, 2 auto)
- **Files modified:** 11

## Accomplishments

- `LlmRequest` gained `FollowUps` (alternating assistant then user, ending on a user turn) and `CacheDocument` as init members; the positional constructor is unchanged, so every existing caller compiles as before.
- `AnthropicLlmGateway` builds `[user(document, prompt), assistant, user, ...]`, sets `cache_control: ephemeral` on the document block only when asked, and refuses non-alternating or assistant-final (prefill) conversations with an `ArgumentException` naming `FollowUps` before any HTTP request. Without follow-ups and caching the body is the Phase 1 shape.
- `LlmSpike --schema-probe` (with an offline `--dry-run`) and `just schema-probe` (cap US$0.25, key resolved through `_with-provider-key`) produced `docs/spikes/02-schema-probe.md`.
- `docs-check` now also requires a `## Result` heading in the probe document.

## Live probe result (claude-haiku-4-5, case-001.pdf)

| Check | Outcome |
|-------|---------|
| (a) text-only request with the v2 schema (10106 bytes) | accepted, HTTP 200; parsed with `Wire.Options`, 0 pattern violations; input 3551, output 359-360 tokens |
| (b1) first gateway call, max_tokens 16000, non-streaming, `CacheDocument` | accepted; schema-valid invoice with 3 items |
| (b2) repair call with assistant + user follow-up | accepted; schema-valid invoice with 3 items |

- **A1, A2 settled:** the enum without `type`, the `tax_id` alternation pattern and the 14-field item array are within the provider grammar limits.
- **A4 settled:** a 16000 max_tokens request is sent once, non-streaming, with no SDK pre-flight rejection.
- **A5 settled:** `Role.Assistant` compiled and the assistant turn was accepted.
- **Cache (contradicts RESEARCH Pitfall 8):** the one-page request is 7212 tokens (schema and prompt are part of the cached prefix), above the 4096-token Haiku minimum. In the cold run the first call wrote 6321 cache tokens (5m) and read 0, and the repair call read 6321. Later runs in the same minutes hit that entry, so the committed doc shows first-call reads (it carries a hand-added line with the cold numbers). Repairs on one-page cases therefore do reuse the cached prefix on Haiku; plan 02-09 should not assume zero reads.
- **Latency:** first call 7.1-7.4 s, repair call 5.7-5.8 s.
- **Spend:** three runs of the probe: US$0.0224 (cold), US$0.0151, US$0.0151, so US$0.0526 of the US$5 Phase 2 cap (each run within the US$0.25 probe cap). The second and third runs were reruns: the first because its cache note was hard-coded wrong (fixed to report measured values), the third to try for a cold cache, which did not happen because the entry was still live.
